🎨 Blender Import Cheat Sheet

1. Download Model: Click the pink package download button in chat to get your .zip file.

2. Extract Files: Unzip to get both .obj (3D Geometry) and .mtl (Materials).

3. Open Blender: Go to File ➔ Import ➔ Wavefront (.obj).

4. View Materials: Select your .obj file. Switch viewport shading to Material Preview to see colors!
